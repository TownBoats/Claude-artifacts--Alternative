# HTML/SVG 实时预览工具

本项目包含两个独立的HTML文件，提供实时预览功能：

## 1. SVG实时预览工具 (svg-preview.html)

### 功能特点
- 实时编辑和预览SVG代码
- 支持代码格式化
- 多种导出选项：
  - 导出为PNG/JPEG图片
  - 保存SVG文件
  - 复制SVG代码
- 预览控制功能：
  - 缩放（Ctrl+滚轮）
  - 平移（Ctrl+拖动）
  - 重置视图
- 全屏预览模式
- 错误提示和性能监控

### 使用方法
1. 直接在左侧编辑器中修改SVG代码
2. 右侧将实时显示预览效果
3. 使用工具栏按钮进行各种操作

## 2. HTML/CSS/JS三合一预览工具 (html-preview.html)

### 功能特点
- 分离式编辑器：
  - HTML结构编辑器
  - CSS样式编辑器
  - JavaScript脚本编辑器
- 实时合并预览
- 支持代码格式化
- 导出功能：
  - 保存完整HTML文件
  - 复制完整HTML代码
- 全屏预览模式
- 错误提示

### 使用方法
1. 在三个编辑器中分别编辑HTML、CSS和JS代码
2. 右侧iframe将实时显示合并后的效果
3. 使用工具栏按钮进行各种操作

## 技术特点
- 基于Monaco Editor提供代码编辑功能
- 使用原生DOM API解析和渲染
- 响应式设计，支持窗口大小调整
- 现代化的UI设计

## 运行要求
- 现代浏览器（Chrome/Firefox/Edge/Safari最新版）
- 需要联网加载CDN资源
